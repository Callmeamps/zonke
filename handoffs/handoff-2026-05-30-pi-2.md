### Tool Pattern (after P3 refactor)
```
(function () {
  // --- Constants ---
  // --- State ---
  // --- Pure Functions ---
  // --- DOM: Get Inputs ---
  // --- DOM: Render ---
  // --- DOM: Screens ---
  // --- DOM: Processing ---
  // --- DOM: Boot ---
  // --- DOM: Event Wiring ---
  // --- Init ---
})();
```

### Screen Flow (all tools)
1. `screen-splash` → boot sequence → btn-start appears
2. `screen-input` → user enters data → btn-analyze/btn-forecast
3. `screen-processing` → batch animation → results
4. `screen-results` → display → btn-gate (email gate)
5. `screen-complete` → success → btn-restart-complete

### Restart Flow (all tools, standardized)
1. Reset inputs to defaults (via `toolResetAndShowInput`)
2. Show `screen-input` (not splash)
3. No `location.reload()` anywhere
