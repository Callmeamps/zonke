## Template Selection Guide

| Goal | Best Template(s) | Reason |
|------|------------------|--------|
| Maximum urgency | B (Terminal Countdown), C (Alert) | Countdown + error states create FOMO |
| Data credibility | D (Data Viz), O (Perf Compare) | Benchmarks, charts, metrics |
| Problem clearly stated | A (System Override), G (Error 404) | "Your competitor is faster" is direct |
| Solution demonstration | L (Chat), K (Wizard) | Shows how it actually works |
| Transformation story | F (Before/After), M (Timeline) | Visual before → after journey |
| Technical appeal | E (Code), J (Directory), N (Network) | Speaks engineer/IT language |
| Relatable/search context | I (Search Results) | Meta humor, "we've all been here" |
| Update/upgrade angle | H (System Update) | Version upgrade metaphor resonates |

## Rendering Tips

- Feed ads (1:1) look best at 1080×1080
- Stories (9:16) require more vertical space - test readability at actual phone size
- Facebook Feed landscape (1200×628) may need adjusting - wider templates may need slight layout tweaks (adjust column ratios)
- All templates designed to work at 2x retina resolution automatically via Puppeteer

### Adjusting for Different Ratios

If a template doesn't fit a new dimension:
1. Look for fixed-width containers: change to percentage-based
2. Check absolute positioning: convert to flex/grid
3. Test visually and tweak CSS

## Next Steps After Rendering

1. **Quality check** each PNG at 100% zoom on mobile
2. **Compress** using TinyPNG (save 30-50% file size)
